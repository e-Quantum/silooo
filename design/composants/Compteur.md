# Compteur

Le compteur mécanique affiche le Donar comme le totalisateur d'une machine : un cylindre crème par chiffre, l'unité en laiton à droite. C'est la signature de Silooo.

- Trois chiffres au plus, une virgule, puis l'unité : 84,3 Md · 1,2 aa · 512 k.
- Quand le Donar monte, seul le dernier cylindre tourne (animation par images, 3 images).
- Toujours précédé de l'icône Donar. Jamais pour les Lingots ni les Gemmes (`sa-monnaie`).
