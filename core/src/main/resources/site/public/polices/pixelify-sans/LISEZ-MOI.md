# Pixelify Sans

La police de texte de Silooo Atelier (`corps` dans la charte du design), servie par le site.

- Paquet npm : `@fontsource/pixelify-sans`, version 5.3.0.
- Fichiers : `pixelify-sans-latin-400-normal.woff2` et `pixelify-sans-latin-600-normal.woff2`, sous-ensemble latin, graisses 400 et 600.
- Licence : OFL 1.1 (SIL Open Font License), le texte est dans le fichier de licence de ce dossier.
- Recopié tel quel depuis le paquet : on ne retouche pas ces fichiers. Pour changer de version, retélécharger le paquet
  (`npm pack @fontsource/pixelify-sans`) et remplacer les fichiers et cette note.
