# Silkscreen

La police des petites légendes de Silooo Atelier (`etiquette` dans la charte du design), servie par le site.

- Paquet npm : `@fontsource/silkscreen`, version 5.3.0.
- Fichier : `silkscreen-latin-400-normal.woff2`, sous-ensemble latin, graisse 400.
- Licence : OFL 1.1 (SIL Open Font License), le texte est dans le fichier de licence de ce dossier.
- Recopié tel quel depuis le paquet : on ne retouche pas ces fichiers. Pour changer de version, retélécharger le paquet
  (`npm pack @fontsource/silkscreen`) et remplacer les fichiers et cette note.
