# Références du site, lisibles hors ligne

Copies des maquettes et du prototype publiés sur claude.ai, pour les sessions qui n'y ont pas accès. Les images
viennent de `design/` par des chemins relatifs : ouvre les fichiers depuis le dépôt, dans un navigateur.
Les polices viennent de Google Fonts : sans réseau, une police de secours les remplace, la mise en page reste juste.

| Fichier | Ce que c'est |
| --- | --- |
| `oooscar-vivant.html` | Le prototype d'Oooscar : pièces SVG (corps, visages, bras à sept angles, toit à six inclinaisons), réactions, nuit, `prefers-reduced-motion`. Base de `oooscar.js` |
| `maquettes/SiteAttente.html` | Page d'attente, téléphone (390 px) |
| `maquettes/SiteInscription.html` | Inscription en trois écrans : le choix, inscrit par Xbox, compte enfant refusé |
| `maquettes/SiteAttenteBureau.html` | Page d'attente, ordinateur |
| `maquettes/SiteRejoindre.html` | Rejoindre, onglet Console |
| `maquettes/SiteBoutique.html` | Boutique : les packs, la fenêtre d'achat |
| `maquettes/SiteClassements.html` | Panthéon, salle des entreprises |
| `maquettes/SiteVote.html` | Vote et jauge de la Vote party |
| `maquettes/SiteGuide.html` | Une page du Guide générée (la Scierie) |
| `maquettes/SiteActu.html` | Un article d'Actus au plan fixe |
| `maquettes/SiteVitrine.html` | La vitrine après l'ouverture, ordinateur |
| `maquettes/SiteIle.html` | Storyboard de l'île qui se construit, six étapes |
| `maquettes/SiteCompte.html` | Espace joueur : Mon entreprise |
| `maquettes/SiteLier.html` | Lier son compte Discord : le code, puis « Relié ! » |
| `maquettes/SiteAdmin.html` | Admin : inscriptions |

Les maquettes montrent la mise en page et le ton. Les noms d'entreprises, les nombres de joueurs et les dates sont
des exemples ; les prix des packs et les chiffres de la Scierie viennent de `definitions/`. Les classes `sa-*`
viennent du design system, les classes `w-*` sont celles du site : `site.css` les reprend. Les sources vivantes :
maquettes https://claude.ai/artifact/7uBWLYneMcH3uwBMWNwXbz (page « Site silooo.com »), prototype
https://claude.ai/artifact/QP9SVPhG4ui1zX2wyjMj5H.

Le dossier `captures-revision/` tient les seize captures (JPEG, 360 et 1 280 px) qui servent de preuve dans
[../../site-revision.md](../../site-revision.md) : le site de `main` rendu en local le 5 novembre 2026, dans les deux modes.
